# 把桩 · Ba Zhuang

**一窑火，十二个时辰，一片瓷告诉你火候。**

景德镇柴窑的一夜。你是把桩师傅：满窑、烧窑、开窑。全游戏没有温度计——判断火候的唯一精确手段，是从火眼里钩出一片**火照子**，看它的釉熔到什么程度。

> 浏览器直接玩，无需登录、无需安装、无需联网。

## 玩

- 一局三夜，每夜 5–7 分钟，共 15–20 分钟。
- **满窑**：点一件器，再点一个窑位。窑头最热、窑尾最凉；选中器时每个窑位会告诉你它会「过火 / 合适 / 生烧」。
- **烧窑**：按住「投柴」，用「火眼」调风。右侧火路是这一窑该走的温度曲线，你要让自己的火贴着它走。每夜三次「火照子」。
- **开窑**：一件件出窑，过火、生烧、合格、精品，偶尔窑变。
- 键盘：`空格` 投柴 · `1–4` 火眼 · `Q` 拉火照子 · `Enter` 继续。

## 里面是什么真东西

| 游戏里 | 景德镇的行当 |
|---|---|
| 火照子 | 把桩师傅从火眼钩出瓷片看釉的熔融程度，用来判断停火时机；这是柴窑没有温度计时代的"仪表"。 |
| 窑头 / 窑身 / 窑尾 | 柴窑沿长度方向温度递减，同一窑里不同窑位的火候不一样。 |
| 满窑分火位 | 不同釉、不同器型要放进不同火位的匣钵柱，放错就过火或生烧。 |
| 升温曲线 | 升温太快会惊釉、炸器；太快或太慢都影响发色。 |
| 窑变 | 还原气氛与温度共同作用下的偶发呈色，不可复制。 |

## 跑

```bash
npm ci
npm run dev        # 本地开发
npm run build      # 产出 dist/，纯静态，可放任意静态服务器
npm test           # 模拟层单元测试
bash scripts/verify.sh   # 类型 + 单测 + 构建 + 卫生 + 浏览器端到端
```

`dist/` 里的资源路径全是相对的，`file://` 双击 `index.html` 也能玩。

## 技术

- TypeScript strict + Vite，**零运行时依赖**。
- 瓷器、火焰、窑体、烟、星空、图表全部 Canvas 2D 程序化绘制，没有一张图片素材。
- 音效全部 WebAudio 合成（噪声 + 滤波 + 振荡器），没有一个音频文件。
- 模拟层（`src/sim/`）是纯函数，可单测；渲染层（`src/render/`）只读状态。
