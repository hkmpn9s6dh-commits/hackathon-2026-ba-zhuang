## 1. 作品名

**把桩**（Ba Zhuang · The Kiln Master）

## 2. 一句话

一窑火，十二个时辰，一片瓷告诉你火候。

## 3. 作品说明（可直接贴进问卷 / 作品说明文档）

把桩，是景德镇柴窑里掌火的人。烧一窑要一昼夜，窑里没有温度计——他靠的是从火眼里钩出一片**火照子**，看釉熔到什么程度，决定还烧不烧。

《把桩》把这一件事做成了游戏的全部：

- **满窑**：十二个窑位，窑头最热、窑尾最凉。青花要吃中火、霁红要吃大火、影青怕过火。点一件器，每个窑位会立刻告诉你它会「过火 / 合适 / 生烧」。
- **烧窑**：按住投柴、调火眼，让火贴着「火路」走完十二个时辰。火有惯性：加太猛会惊釉，压太狠会生烧。全游戏只有三次**火照子**，用完就只能靠火色猜。
- **开窑**：一件件出窑。过火流釉、生烧发灰、合格、精品，偶尔窑变。按订单结账，进下一夜。

一局三夜（试烧 / 官窑订单 / 贡瓷），15–20 分钟。浏览器打开即玩，不用登录、不用安装、不联网。

**文化依据**：火照子、火位（窑头/窑身/窑尾）、匣钵、升温曲线、还原焰、窑变，都对应柴窑真实工序；每一项机制在作品说明的对照表里都写了出处。

**为什么适合这个赛道**：它不是给瓷器贴一层国风皮肤，而是把「看火」这门只能口传的手艺，翻译成一个可玩、可失败、可复盘的判断循环。玩家玩完会记住一件事：**把桩师傅没有温度计，他有一片瓷。**

## 4. 运行 / 玩法说明（运行包里的 README）

```bash
npm ci
npm run build     # 产出 dist/
# 打开 dist/index.html，或把 dist/ 放到任意静态服务器
```

线上试玩：见第 8 节。

操作：鼠标点选瓷器与窑位；烧窑时按住「投柴」，点 0–3 切火眼，点「火照子」拉瓷片。
键盘：`空格` 投柴 · `1–4` 火眼 · `Q` 火照子 · `Enter` 继续。

| 教学 / 社会价值 | 满窑火位、升温曲线、匣钵、窑变都是真工序；可作研学课程的互动环节，也可嵌进景区互动屏。 |

| **可玩性（官方优先项）** | 核心是「判断—下注—揭晓」：押火位、押火候、开窑见分晓。失败也有信息量，下一窑立刻想再来。 |

## 6. AI 使用说明（官方要求如实说明）

- **用了**：AI 编程助手（Agent 形态，能读写工程、跑测试、开浏览器自检）参与策划、代码、程序化美术与文案；作者定方向、定验收条件、做取舍与验收。
- **没用**：没有用 AI 生成图片或音频素材。游戏里所有图像与声音都是代码在运行时绘制/合成，因此不涉及第三方素材授权。
- **怎么保证**：先写可判定的验收条件（`docs/01-SPEC.md` 第 4 节），测试与实现同步；每版都在真实 Chromium 里跑通一局并看截图改画面。
