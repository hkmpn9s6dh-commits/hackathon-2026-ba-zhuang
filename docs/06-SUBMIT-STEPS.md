## 0. 需要你准备的三样

| 东西 | 在哪 | 说明 |
|---|---|---|
| 负责人姓名 + 手机号 + 邮箱 | 你自己 | 登记与提交两次必须一致，不能改 |
| 队名 | 自己起（建议「一把火」或真名） | 1–3 人，个人也能报 |
| 意向赛道 | 文旅融合（窑火相传） | 我们做的是这个 |

## 1. 先登记（约 5 分钟，不用交作品）

1. 打开上面的问卷，选「**首次参赛登记**」。
2. 填：负责人姓名、手机号、邮箱、队伍名称、队伍人数（1）、**意向赛道：文旅融合**。
3. 提交。**截图保存**提交成功页。

## 2. 提交作品（约 15 分钟）

再进同一个问卷，选「**已登记，提交或更新作品**」，然后：

1. **作品名称**：把桩
2. **一句话介绍**：一窑火，十二个时辰，一片瓷告诉你火候
3. **作品说明**：贴 `docs/05-SUBMISSION.md` 第 3 节全文
4. **可体验作品**：填线上试玩链接（见下）
5. **上传 ZIP**：`把桩-提交包.zip`（见第 3 节）
6. 勾选并阅读《作品权利声明与赛事评审、展示及传播授权协议》
7. 提交。**截图保存**提交成功页。
