# 07 — UI：《把桩》

> 闸 A 写 §1–4；§5 之后只在实测后补。基线视口 1440×900。

## 1. 风格预设：*夜窑*

一间柴窑的剖面，外面是夜，里面是火。整屏只有四种颜色在场：**夜青、窑火、瓷白、青花**。界面不是面板墙，是「窑具」——字写在瓷片、柴牌、窑砖上；凡是能用画的，不写字。

| Token | 值 | 用途 |
|---|---|---|
| `--night` | `#080d16` | 窑房外的夜，全局底色 |
| `--night-2` | `#101a2a` | 稍亮的夜，分区背景 |
| `--brick` | `#241a14` | 窑砖（暗部） |
| `--brick-lit` | `#4a2c1c` | 被火照亮的窑砖 |
| `--fire` | `#e2571f` | 火的基色 |
| `--fire-hot` | `#ffc46b` | 火心、高光 |
| `--porcelain` | `#f3efe4` | 瓷白（正文、器身） |
| `--porcelain-dim` | `#cfc7b6` | 瓷的暗部、次要文字 |
| `--cobalt` | `#2f5aa8` | 青花：唯一的交互色（可点、选中） |
| `--celadon` | `#9ec4b8` | 影青：良品判定 |
| `--copper` | `#a83a2a` | 釉里红：失败/危险 |
| `--gold` | `#c9a35a` | 金：只在「窑变」与结局出现 |

- **字体**：标题与器物名 `Songti SC / SimSun / serif`（刻版感），正文与数字 `Microsoft YaHei / PingFang SC / sans-serif`（小字清楚）。不外链。
- **字号六级**：12 / 13 / 15 / 17 / 21 / 30，另加标题 56。正文不小于 15px（中文）。
- **规矩**：圆角只在瓷片标签上用（2px，模拟瓷片磨边）；不用投影堆叠，不用渐变按钮；**青花一屏最多三处**（当前可点的东西、选中的东西、主按钮）。火的颜色只出现在窑里，不跑到界面上。
- **动效**：火焰 60fps 粒子；开窑时热浪用 0.6 秒的白雾；`prefers-reduced-motion` 时粒子减半、白雾改为 0.2 秒淡入。

## 2. 尺子 —— 什么算好

| 参考 | 学哪一点 | 不学什么 |
|---|---|---|
| 《匠木》（腾讯 NEXT） | 把一门传统工艺的**手感**做成唯一玩法：工艺细节本身就是关卡，不靠外挂小游戏。 | 它的关卡关卡式结构（我们是连续的一夜）。 |
| 《折扇》（腾讯） | 单一物件的**工序**拆成可点触的步骤，界面像工具台而不是菜单。 | 它的科普弹窗（我们把说明放进器物点评里）。 |
| 《Frostpunk》 | 温度与资源用**整屏的冷热对比**讲，仪表退到边上，一眼看到"世界在变冷/变热"。 | 它的重 UI 面板与多层菜单。 |
| 《This War of Mine》 | 剪影 + 夜：资源决策的重量来自"东西本来就不多"。 | 它的灰暗到看不清（我们要能看清瓷器）。 |
| 《Papers, Please》 | 一次判断决定后果；紧张感来自**信息不全**，不是计时条。 | 它的表单堆叠。 |
| 《江南百景图》 | 中国风的界面秩序：颜色少、字距宽、没有多余装饰。 | 它的卡片网格化。 |

过线的意思：把主屏和这六件混在一起盲排，评委第一眼能停下，并且说得出"这是在烧窑"。

## 3. 一个记忆点

**把桩师傅没有温度计，他有一片瓷。**

全游戏没有数字温度计。判断火候的唯一精确手段，是从火眼里钩出一片**火照子**：特写里那片瓷，釉面从哑到亮、从挂珠到流平，三档肉眼可辨；旁边的读数只在拉出来的一瞬出现。三次机会，用完了就只能靠火色猜。

其余一切（时辰、柴数、铜钱）都要安静到不抢这一句话：时辰是顶部十二个小点，柴数是一个数字，铜钱只在结算出现。

## 4. 主屏规格

**构图**（1440×900，三段式，1px = 1px）：

```
┌──────────────────────────────────────────────────────────────┐
│ 顶部 56px：夜次·夜名（左）  十二时辰点（中）  柴 / 铜钱（右）    │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  场景层（canvas，100% × 100%）                                 │
│   左：火膛开口（圆形，直径 180，y 居中偏下）                     │
│   中：窑室剖面 3×3（每格 132×132，间距 18，整体居中）            │
│   右：烟囱（宽 64，通到顶部）+ 烟                              │
│   底：窑砖地平线 y=760，砖缝每 64px                             │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ 底部 156px：托盘 / 操作条（同一位置换内容，不叠加）              │
└──────────────────────────────────────────────────────────────┘
```

- **窑位格**：132×132，边框 1px `--brick-lit`；放置后格内是瓷器剪影 + 底部一行 13px 器名。预判用格内左下角一枚 8px 圆点：青花=合适、铜红=过火、灰=生烧，并在格上方浮 12px 小字。
- **瓷器卡（托盘）**：116×132，器身画在卡上（不是图标），名 13px，火候带用一条 4px 的横条表示（影青偏左、青花居中、霁红偏右）。
- **烧窑操作条**：左「投柴」大按钮 168×64（按住生效），中「火眼」四档（0–3，每档 40×40），右「火照子 ×3」按钮 132×48。全部在拇指/鼠标一下够到的位置。
- **火路**：竖在场景右侧、烟囱左边，宽 72，高 520。目标曲线是 `--porcelain-dim` 的 2px 虚线；你的火是 `--fire-hot` 的 3px 实线；两条线之间的偏差区用半透明铜红填充（只在超差时出现）。
- **事件卡**：居中 520×300，瓷片底（`--porcelain` 92% 不透明），标题 21px，两个选项各一行 17px，整卡最多两个按钮。出现时时间暂停，底色压暗 40%。
- **开窑**：器物依次从窑门"出来"，落在桌面上排成一行，每件下方一枚瓷片标签写判定（合格/精品/过火/生烧/窑变），标签 88×28，13px。

**响应式**：
- ≥1280：上述规格。
- 900–1280：场景等比缩到 0.82，操作条不缩。
- <900（竖屏手机）：场景改为上下两段——上半窑体（高度 52vh），下半操作条与托盘；窑位格缩到 96×96，仍保持 3×3。


## 5. 引导：老师傅在旁边嘀咛（实测后补，2026-11-13）

用户第一轮试玩的原话：「我压根不知道怎么去推进，中间卡住了之后挫败感很强」。所以加了**弱引导**，不做弹窗、不做箭头、不做教程关：

- **一句话**：屏幕底部偏中，宋体 16px，前面一枚火漆红点，随状态换词。全游戏只有这一处在"教你"。
- **会呼吸的落点**：当前该动的那个控件（托盘第一件器 / 一个空窑位 / 封窑 / 投柴 / 火照子 / 下一件）加 2.4 秒一圈的暖色呼吸环。不给箭头，只给"这里活着"。
- **为什么会卡**：`封窑` 在没放器时是禁用的——以前没有任何解释，现在提示会说「先点托盘里的一件器，再点一个窑位」；放了一部分时说「还有 N 件没入窑；不想放了就直接封窑」。
- **不打断**：事件卡与火照子特写出现时，提示自动消失（那两块自己会说清楚）。

判定标准（e2e AC-15）：进入满窑必须有一句提示；封窑之后必须换成烧窑的提示。

### 5.1 第二轮：用户看不懂术语（2026-11-13 下午）

用户原话：「火眼 0123 干是干什么的我都不知道，只能按照他大致讲解一个一个尝试」「火照子我也不知道干嘛，中间浪费了几个」「放回去之后就没效果」。

| 控件 | 改法 |
|---|---|
| 火眼 | 标题改「火眼」，后面跟一句「风门：开大升得快，收小更稳」；四个按钮从纯数字改成 `0 闭 / 1 微 / 2 中 / 3 大` 两行 |
| 投柴 | 按钮内加「按住」小字（原来只有按钮名，没人知道要按着不放） |
| 火照子 | 按钮内加「钩一片瓷看火候」；面板里除了「未熟/正到/过火」，再加一行有箭头的行动建议：「→ 回去补柴，把火顶上去」；关掉之后，底部提示继续挂着同一句 9 秒，并且在火路图上留一枚小三角，位置就是你拉片的那一刻、颜色是结论 |
| 火路图 | 右上角加标题「火路」与两行图例（虚线 该走的路 / 实线 你的火）；第一夜开局的前 6 秒，提示会先讲这张图怎么看 |

### 5.2 开窑与清点：交互太单调

用户原话：「一件一件拿出来的时候，我以为点一下就可以了……交互上面感觉很单调，然后不明所以」。

- 开窑不再只有「出下一件」按钮：**窑里的每件器自己就是一个可点的热区**（底部一枚「取」标签 + 呼吸环），点哪件取哪件，取出来那件当场显示判定；「全部取出」作为退路。
- 清点从纯文字列表改成**一排实物**：每件画出来、下面挂判定标签；顶部一行「成器 5/5　最好的一件：影青刻花碗（精品）」，下面才是明细与账。
