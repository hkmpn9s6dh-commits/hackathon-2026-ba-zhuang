把桩 · 运行说明
================

一、最快的方式
  双击 index.html（Chrome / Edge / Safari 均可），直接开始。
  不需要安装、不需要联网、不需要登录。

二、如果双击打不开（部分浏览器限制本地文件）
  在本文件夹里开一个命令行，执行：
      python -m http.server 8000
  然后浏览器打开 http://127.0.0.1:8000/

三、放到服务器
  把本文件夹整体上传到任意静态服务器即可；资源路径全是相对的。

四、怎么玩
  一局三夜：满窑（点火位）→ 烧窑（跟火路）→ 开窑（见分晓）。
  屏幕上始终有一句提示告诉你下一步做什么，该动的那个按钮会缓慢呼吸。
  满窑：点一件瓷器，再点一个窑位。窑头最热、窑尾最凉；写着「合适」的那一格最稳。
  烧窑：按住「投柴」加火，点 0-3 调火眼；每夜三次「火照子」——
        从火眼钩一片瓷出来看釉熔到哪，这是全游戏唯一的精确仪表。
  开窑：一件件出窑，按订单结账，进下一夜。

  键盘：空格 投柴 · 1-4 火眼 · Q 火照子 · Enter 继续
